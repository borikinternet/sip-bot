# SIP-ассистент «Василиса»

Демонстрационный русскоязычный SIP-бот: принимает звонок через FreeSWITCH, распознаёт речь, ищет релевантные фрагменты в локальной базе знаний, формирует ответ локальной LLM и озвучивает его. Поддерживает контекст разговора и перебивание; рассчитан на **один одновременный звонок**. Это MVP для изучения и демонстрации технологий, не готовый production-сервис.

## С чего начать

- [Журнал развёртывания для мастер-класса](artifacts/workshops/sip-bot-deployment-20260929/execution-journal.md) — фактический прогон в чистой Ubuntu WSL: команды с пояснениями, FreeSWITCH с двумя очередями, модели, источники, контрольные суммы, исправления и результаты проверки. Тяжёлые модели и подготовленный no-GIL runtime в репозиторий не входят; приведённые в журнале команды скачивания вместо локальных копий **не выполнялись** в этом прогоне.
- [Текущий handoff](HANDOFF.md) — что именно подтверждено, что осталось проверить и где продолжать работу. [Предыдущий снимок публичного демо](docs/handoffs/HANDOFF-2026-09-25-public-route.md) сохранён отдельно.
- [Пользовательский гайд](docs/user-guide.md) — роли, конфигурация и запуск существующего демонстратора. Более поздние факты развёртывания сверяйте с журналом выше.
- [Мастер-класс FreeSWITCH](docs/workshops/freeswitch-callcenter-runbook.md) и [подготовка собственного RAG-корпуса](docs/workshops/rag-corpus-onboarding-runbook.md) — отдельные практические инструкции.

[Архитектура](docs/architecture.md), [техническое задание](docs/technical-specification.md) и [дорожная карта](docs/roadmap.md) описывают принятые границы и дальнейшую работу. Код проекта опубликован под [MIT](LICENSE); условия использования моделей и других внешних компонентов разбираются [отдельно](docs/licensing-policy.md).

Контрольный SIP-звонок в новом стенде 29 сентября прошёл, но отчёт о «завершённом переводе» пока использует имитацию результата оператора. Фактический SIP-перевод на человека и полный браузерный звонок через публичный сайт не следует считать проверенными — детали и ссылки на evidence находятся в [handoff](HANDOFF.md).
