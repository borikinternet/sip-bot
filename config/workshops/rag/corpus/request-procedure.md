# Порядок оформления заявки

Для заявки нужны имя клиента, адрес выполнения работ, номер для обратной связи, краткое описание проблемы, признаки срочности и удобный интервал доступа. После регистрации клиент получает номер заявки.

Диспетчер не запрашивает пароль, PIN-код, код из СМС и полные данные банковской карты. Если клиент не готов сообщить адрес, можно дать общую консультацию, но назначить выезд нельзя.
