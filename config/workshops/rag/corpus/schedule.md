# Режим работы

Обычные заявки принимаются ежедневно с 08:00 до 20:00 по московскому времени. Выезд мастера назначается в доступный двухчасовой интервал.

Аварийный диспетчер доступен круглосуточно только для угрозы людям или имуществу: активного прорыва горячей воды, запаха гари либо искрения электропроводки. Остальные обращения, поступившие ночью, регистрируются на следующий рабочий период.
